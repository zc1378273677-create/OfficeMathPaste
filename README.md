## 项目介绍

**My Better Office** 是一个面向 Windows 桌面版 Microsoft Word 和 PowerPoint 的公式粘贴增强工具。

它保留 Office 原有的复制粘贴习惯，只需使用熟悉的 `Ctrl+C` 和 `Ctrl+V`，即可将网页、ChatGPT 回答或 LaTeX 文本中的数学公式转换为 Office 原生公式。

无论是整理数学作业、撰写科研论文，还是制作学术演示文稿，都可以让正文与数学公式一起粘贴，并在 Office 中继续编辑。

目前项目主要适配 Office 2016 和 Office 2021。

特别感谢我的好兄弟 **牢安**，帮助完成了 Office 2021 的适配工作。仓库中已经提供对应的 Office 2021 修复版本，欢迎使用和反馈！

> **版本说明**
>
> - Office 2016：原始适配版本。
> - Office 2021：由牢安协助完成适配，仓库提供对应修复版本。
> - 两个版本的 Office 内部组件和安装环境可能存在差异，请根据自己的 Office 版本选择对应安装包。
>
> 本人日常使用 Microsoft Office 专业增强版 2016。Word 和 PowerPoint 的常规复制粘贴已在本机测试通过。Office 2021 适配版本也已纳入项目，欢迎反馈实际使用情况。

## 功能特性

- **原生快捷键操作**：无需额外快捷键，直接使用 `Ctrl+C`、`Ctrl+V`。
- **Office 原生公式**：转换结果可以在 Office 公式编辑器中继续修改。
- **正文与公式混合粘贴**：支持中文、段落以及部分加粗、斜体样式。
- **多种公式格式识别**：支持 `\(...\)`、`\[...\]`、`$...$` 和 `$$...$$`。
- **网页公式恢复**：支持从带 LaTeX 注释的 KaTeX 富文本及部分 MathML 内容中提取公式。
- **常见数学结构**：支持分式、根号、上下标、求和以及多行 `aligned` 公式。
- **求和符号优化**：关闭求和号随嵌套内容自动拉伸的行为，改善多重求和的显示效果。
- **中文安装菜单**：提供安装、更新、还原等操作。
- **安装状态备份**：安装前备份加载项注册信息，方便后续恢复。

## 安装与更新

1. 从 GitHub 仓库下载最新 ZIP 安装包。
2. 根据 Office 版本选择对应的安装版本。
3. 解压安装包。
4. 保存文档，完全退出 Word 和 PowerPoint。
5. 双击运行 `install.cmd`。
6. 输入 `1`，按 Enter 完成安装或更新。
7. 重新打开 Word 或 PowerPoint，即可使用。

**注意：Office 2016 和 Office 2021 请使用仓库中对应的适配版本，不要混用不同版本的修复文件。**

安装程序会将文件复制到当前用户的应用目录，并注册 COM 加载项，通常不需要管理员权限。

### 安装菜单

```text
[1]  安装 / 更新
     启用 Word 和 PowerPoint 的 Ctrl+V 公式转换

[2]  还原
     恢复首次使用本安装包之前的加载项状态

[3]  退出
```

菜单会显示安装状态和 Office 运行状态。操作完成后按 Enter 返回菜单。

### CMD 命令

在解压目录中打开普通 CMD，可以直接运行：

```bat
install.cmd
install.cmd install
install.cmd restore
```

| 命令                    | 用途         |
| --------------------- | ---------- |
| `install.cmd`         | 打开中文菜单     |
| `install.cmd install` | 安装或更新      |
| `install.cmd restore` | 恢复首次安装前的状态 |

更新时直接选择 **1** 即可。首次安装前的备份会保留，后续更新沿用这份备份。

## 使用示例

安装完成后，在 Word 正文或 PowerPoint 幻灯片文本框中粘贴以下内容：

```latex
这是一个公式：\(\frac{a}{b}+\sqrt{x}\)。
```

预期效果：

正文正常显示，分式和根号转换为 Office 原生公式，可以继续编辑。

### 多行公式与正文

例如复制以下内容：

```latex
解方程组，得：

\[
\begin{aligned}
a_0 &= 13.45966387 \\
a_1 &= -3.60530940 \\
a_2 &= 0.26757066
\end{aligned}
\]

因此，所求最小二乘二次拟合多项式为：

\[
P_2(x)=13.45966-3.60531x+0.267571x^2
\]
```

正文、公式和段落可以一起粘贴。

也可以直接选中网页中已经排版好的正文和公式，一起复制。能否恢复精确公式，取决于来源网页放入剪贴板的内容。

## 还原与清理

运行 `install.cmd`，选择 **2**，即可恢复首次使用安装包之前的加载项注册状态，并移除本安装包部署的程序与备份。

> **重要提示**
>
> 如果首次安装前已经使用过测试版，还原会恢复测试版的注册信息。请保留这些注册信息指向的旧目录，直到确定不再需要回退。

安装目录：

```text
%LOCALAPPDATA%\BatterOffice\OfficeMathPastePackage\
├── app\         当前运行的加载项与转换引擎
└── original\    首次安装前的注册信息备份
```

安装完成后可以删除旧 ZIP 和解压副本。建议保留最新安装包，方便后续更新或还原。

## 速度与工作原理

加载项启动时准备转换引擎，同一 Office 应用中的后续粘贴复用该进程，减少重复启动和加载模块的时间。

### 转换流程

```text
网页富文本 / LaTeX
        ↓
识别公式并提取源码
        ↓
LaTeX → MathML → Office Math（OMML）
        ↓
Word 文档 / PowerPoint 文本框
```

### 技术组成

| 组件                 | 作用                     |
| ------------------ | ---------------------- |
| C# COM 加载项         | 接入 Office，读取剪贴板并插入转换结果 |
| Python             | 识别、转换和生成临时文档           |
| latex2mathml       | 将 LaTeX 转换为 MathML     |
| lxml 与 Office XSLT | 生成 OMML 公式结构           |
| 常驻转换进程             | 在多次粘贴间复用转换组件           |

### 性能测试

开发时使用同一条三重求和公式进行了预热后的 20 次连续测试：

| 转换目标       | 转换耗时中位数   |
| ---------- | --------- |
| Word       | 约 6.2 ms  |
| PowerPoint | 约 11.5 ms |

以上数据来自开发机的 Turbo 版测试，计时覆盖转换请求到临时文件生成。Office 实际插入、渲染以及首次初始化还会增加耗时，复杂内容的结果也会不同。

**所有公式转换均在本机完成。** 程序通过临时文件和本地进程管道处理粘贴内容。

## 使用范围与限制

- 当前主要面向 Word、PowerPoint，其他 Office 应用尚未适配。
- 主要支持明确的公式分隔符，或富文本中可以提取源码的公式。没有分隔符的裸 LaTeX 暂不自动识别。
- 网页必须提供可恢复的文本、LaTeX 或 MathML。只有图片的公式无法通过此工具识别。
- LaTeX 支持范围受转换库限制。复杂宏、自定义命令和部分环境可能保留原文或转换失败。
- `aligned` 当前转换为两列对齐结构，复杂的多对齐列布局可能需要进一步适配。
- 正文格式主要包括基本段落、加粗和斜体。网页图片、复杂表格和完整 CSS 排版尚未完整支持。
- PowerPoint 插入时会使用 Office 剪贴板，后续粘贴可能使用转换后的 PowerPoint 内容。
- macOS、网页版 Office 及其他尚未验证的 Office 版本不在当前适配范围内。

## 常见问题

\<details>
\<summary>安装提示 Word 或 PowerPoint 仍在运行\</summary>

先保存文档并完全退出两个应用，再返回菜单操作。如果窗口已关闭但仍提示运行，可以在任务管理器中检查是否还有相应进程。

\</details>

\<details>
\<summary>Office 提示加载项出现问题，或者粘贴后还是公式代码\</summary>

记录使用的 Office 版本和触发问题的原始公式。

如果 Office 已禁用加载项，可以在“文件 → 选项 → 加载项”查看状态。

更新安装前先退出 Office，重新打开后再次测试。

请在反馈中说明是整段复制失败，还是单独复制公式也失败。这有助于定位剪贴板格式和公式解析问题。

\</details>

\<details>
\<summary>第一次粘贴比后续粘贴慢\</summary>

第一次可能需要等待转换引擎初始化。Turbo 版会复用已启动的引擎，后续粘贴通常更快。

\</details>

\<details>
\<summary>下载安装包后，脚本被 Windows 阻止\</summary>

先确认安装包来源可信。如果文件属性中有“解除锁定”，可以在解压前解除 ZIP 的下载锁定后重新解压。

单位电脑可能有脚本或加载项管理策略，需要由管理员按组织要求处理。

\</details>
